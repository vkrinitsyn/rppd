# rppd 0.2.4

2025-04-27, with work until 2026-02-17 under the same version.

## New

- A function's `print` output is captured and stored in the database; log messages carry a
  prefix.
- Integration features for a function call, for an embedder.
- A flag that tells a trigger to ignore a change.
- **The trigger as a C library:** the PostgreSQL extension in C (`rppd-pg-c`), its `.so` file
  named with the version.

## Changed

- The runtime re-configuration is public; the configuration compares with `Eq`.
- The repository is a cargo workspace: `rppd` and `rppd-common`.

## Fixed

- The exit code.
