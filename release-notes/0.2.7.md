# rppd 0.2.7

2026-09-16.

## New

- **ClickHouse client `CH`.** With `ch_url` set, every function gets a `clickhouse_connect`
  client as `CH`, beside `DB`. It needs the python `clickhouse_connect` package; without it,
  or with the connection refused, `CH` is left unbound and that is logged. A worked example is
  in `examples/`.
