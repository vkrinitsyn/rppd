# rppd 0.2.19

2026-11-04.

## New

- A column `required_version` of a function: stored only.

## Changed

- **Reloads.** A trigger only marks a table as changed; the monitor reloads it, and every
  table once a minute.

## Fixed

- **Cron:** a reload no longer loses a firing or drops a failed job.
- **Locks:** rppd no longer waits on a locked function row.
- **The C client:** "Unsupported protocol" is fixed. Rebuild `rppd.so`.
