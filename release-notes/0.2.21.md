# rppd 0.2.21

Needs etcds 0.25.0. With it, rppd-common 0.2.5.

## Changed

- Built on etcds 0.25.0 (0.24 before).
- A build with the `lib-embedded` feature is the library: its `rppd` binary only says so and
  exits. Before, that binary did not link.
- Dependencies updated for `cargo audit` (`url` 2.5.9).

## Tested

- New tests, module by module, against a throwaway PostgreSQL with an rppd node on it, and of
  the binary itself: its exit codes for bad arguments and an unreachable database, a start
  and a stop by SIGINT. A machine without PostgreSQL skips those that need one.
