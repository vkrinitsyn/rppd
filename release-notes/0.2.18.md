# rppd 0.2.18

2026-11-02.

## New

- **Test a function: `test(level)`.** A function's code may define
  `def test(level: int = 0) -> int`. An event never runs it; a check runs it and never the
  body: rppd runs the code's definitions only, then `test(level)`, on the master. `0` returned
  is passed; any other value, an exception or no `test` is failed. It is given what a call is
  given (`DB`, `ETCD`, `DF`, `CH`, `SECRET`, `TOPIC`, `TABLE`) and no event; what it leaves
  open in `DB` is rolled back.

## Changed

- Dependencies updated for `cargo audit`.
