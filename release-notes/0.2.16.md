# rppd 0.2.16

2026-10-19. Named for YT Cluster from this version. The first version in the repository after
0.2.7.

## New

- **Secrets, `SECRET`.** Embedded in a YT Cluster node, a function reads values from the
  cluster's secret store: `SECRET.get`, `SECRET.get_bytes`, `SECRET.names`. Only a function
  whose `secret_names` lists a name may open it.
- **Cadence:** a row of `rppd_cron` with `cadence = true` watches a pipeline process that
  feeds an etcd queue, in place of scheduling a job.
- **Circuit breaker:** for a pipeline process that keeps failing.
- **Traffic shaper:** how many calls of a function, how often.
- **Tracing**, and the tables as a schema file (`rppd.yaml`).

## Changed

- **Cron:** only the master runs the jobs; the other nodes keep their schedules moving, so a
  new master does not fire the jobs it missed.
- `cargo audit` in CI; the license file corrected.
